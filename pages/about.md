前端的活儿做了几年，喜欢把复杂的东西收拾干净。白天写 Web，晚上折腾工具和笔记，偶尔写点东西。

## 我在做什么

在一家做数据产品的公司负责 Web 端，主要工作是围绕数据表格的可视化与交互——筛选、聚合、导出、性能优化这类事情。

这类需求有个特点：看起来只是「把数据展示出来」，实际难点几乎都在边界上。十万行不卡、列宽可拖拽、筛选条件可组合可回放，每一条单独看都简单，叠在一起就是另一个项目。

## 我关注什么

- **前端工程化**：构建配置、类型系统、CI 流程，让「改一行代码」这件事足够可预测
- **交互细节**：加载态、空状态、错误态、键盘可达性，这些决定了产品是「能用」还是「好用」
- **写作与知识管理**：想清楚才能写清楚，反过来也一样
- **性能**：不是追求跑分，而是不让人等

## 一路走来

**现在** · 数据产品方向的前端，从需求评审一直做到线上值班。

**之前** · 在电商方向做过两年 C 端页面，那段时间最大的收获是理解了「用户在弱网和旧手机上是什么体验」。

**更早** · 从写脚本处理表格开始接触编程，发现把重复的事自动化掉是件很爽的事。

## 技术偏好

日常主力是 TypeScript + Vue，构建用 Vite。对「加依赖」比较谨慎，能自己写清楚的小工具就不引包。编辑器换来换去最后回到 VS Code，主题是暗色。

## 关于这个站点

用的 VitePress，内容全部是 Markdown，构建后是纯静态页面。部署走 GitHub Actions，推送到 main 就自动发布。选它是因为写作体验足够安静——打开编辑器就能写，不用管路由、样式和后端。
