## 精选项目

### MarkFlow

本地优先的 Markdown 写作工具。文件存在磁盘上，不依赖账号和云同步，支持双向链接与全文检索。

- 技术栈：Vue 3 + TypeScript + CodeMirror 6 + Tauri
- 状态：进行中，自用为主
- 链接：[github.com/fluxixix](https://github.com/fluxixix)

做它的起因是受不了「写作软件要求先登录」。核心约束只有一条：所有数据必须是纯文本文件，放在用户自己选的目录里，卸载软件不能丢东西。

### SheetKit

把 Excel 表格变成内部管理后台的小工具。上传一份表，自动生成带筛选、排序、批量编辑和权限控制的页面。

- 技术栈：React + Node.js + PostgreSQL
- 状态：已归档，启发了不少后续思路
- 链接：待补充

难点不在渲染表格，而在于自动推断出合理的字段类型和校验规则——用户不会给表格写注释，只能靠数据本身猜。最后用了一套「采样 + 置信度」的策略，猜错的字段允许手动改。

### 本站

这个站点本身也算一个项目：VitePress + 自定义主题，文章全部是 Markdown，推送到 main 自动构建发布。

- 技术栈：VitePress + TypeScript + GitHub Actions
- 状态：长期维护
- 链接：[fluxixix.github.io](https://fluxixix.github.io)
